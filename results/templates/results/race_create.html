Comment ça marche ?
  1. Renseignez le nom, la date et le club organisateur.
  2. Après création, une clé API MeOS unique et un lien privé de gestion sont affichés.
  3. Dans MeOS (Outils → Serveur Online) : URL = celle du site, Password = la clé API, numéro de compétition laissé vide, compression ZIP désactivée, format MeOS Online Protocol XML 2.0.
  4. Conservez le lien privé : il permet de retrouver la clé, de la régénérer et d'éditer les informations.
La course apparaît immédiatement sur le site, en attente du premier import MeOS.
